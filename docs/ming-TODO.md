## 배경음악 받는 방식
지금 상태
- 처음 로딩에서 노래 4곡(약 9.8MB)을 뺐음. 처음 로딩 18.9MB → 7.4MB
- 타이틀이 뜨면 랜덤 순서로 한 곡씩 받으면서 재생(스트리밍). 곡이 바뀔 때마다 그 곡을 새로 받기 시작함
- 걱정: 경기 전 영상 로딩·매칭·접속 중에 노래 받기가 겹치면 그쪽이 느려질 수 있음

선택지
- A. 처음엔 한 곡만 받고, 나머지는 설정에서 "추가 음악 다운로드"로 받기
  - 장점: 게임 중엔 음악 때문에 다른 로딩이 느려지지 않음, 데이터 아끼고 싶은 사람은 안 받으면 됨
  - 단점: 설정 화면에 버튼·진행률 추가 필요, 안 받은 사람은 같은 노래만 반복해서 들음
- B. 게임하면서 남는 시간에 알아서 받기
  - 메뉴에 가만히 있을 때만 받고, 경기 영상 로딩·매칭·경기 시작 순간에는 멈췄다가 다시 이어 받기
  - 장점: 사용자가 신경 쓸 게 없음, 결국 모든 곡을 들을 수 있음
  - 단점: 구현이 복잡함(멈춤·이어 받기), 모바일 데이터를 자동으로 씀
- C. 지금처럼 들을 때마다 스트리밍
  - 장점: 추가 작업 없음
  - 단점: 곡이 바뀌는 순간 다른 로딩과 겹칠 수 있음
- 참고: 노래를 96kbps로 다시 압축하면 곡당 약 2.5MB → 2.1MB 정도로 줄일 수 있음 (어느 방식이든 같이 적용 가능)

## 앉기 규칙 (Q)
- 앉아 있으면 높은 공격(주먹, 공중 공격 등)을 피할지
- 앉아 킥을 하단 공격으로 만들지 (서서 가드로 못 막고 앉아서만 막기)
- 앉아서 가드할 수 있게 할지 (아래 + 상대 반대 방향)
- 앉아 킥 맞으면 넘어지기(다운) 효과를 줄지
- 앉아 주먹·앉아 킥 피해량을 일반 공격과 다르게 할지
- 컴퓨터 상대도 앉기를 쓰게 할지

# 변경사항

## 2026-11-15 12:50

연습하기 / 일시정지
- 게임하기 메뉴: CPU · 멀티플레이 · 연습하기
- 연습하기: 상대는 B 또는 G 랜덤, 가만히 서 있는 더미, 체력이 0이 되면 다시 100, 시간 ∞
- 일시정지(CPU 대전·연습하기만): ESC, ☰ 버튼, 모바일 뒤로가기
  - 계속하기 / 설정 / (연습하기만) 캐릭터 선택 / 메인메뉴
  - 게임 화면은 그대로 보이고 어두운 창만 뜸
- ☰ 버튼은 이모티콘 바 맨 앞에 붙어 있음 (PC·모바일 가로·세로 모두)

화면
- 태그를 이번 라운드에 썼으면 태그 버튼·PC 태그 키가 회색, 다음 라운드에 다시 켜짐
- 체력바 아래 YOU/CPU/DUMMY 글자와 TAG 글자 겹침 수정
- PC 방향키 아래 "이동 · 위 점프 · 아래 앉기" 설명 삭제
- CPU 대전 룰렛(상대·스테이지 뽑기) 시간 절반으로 줄임
- 이모트 28번 미리보기 그림 교체

로딩
- 처음 로딩 퍼센트: 받은 용량 기준으로 1%씩 부드럽게 올라감
- 100% 찬 뒤 넘어가는 데 오래 걸리던 것 수정 (그림을 두 번 받던 문제)
- 처음 로딩에서 배경음악 제외 (위 "배경음악 받는 방식" 참고)
- 배경 그림 JPG → WebP (4.4MB → 3.1MB)
- 필살기·태그 영상 다시 압축 (전체 20.4MB → 15.7MB, 화질 거의 동일)
- 경기 전에 두 캐릭터의 필살기·태그 영상을 전부 받은 뒤 시작 (CPU·연습·멀티 모두)
  - LOADING 화면에 % 표시, 멀티는 두 사람 다 받아야 시작 (15초 넘게 신호 없으면 그냥 시작)
  - 영상이 혹시 준비 안 됐으면 검은 화면 대신 컷인만 건너뜀

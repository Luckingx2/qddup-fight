# 큐떱인천

Q, W, E, R, EGG, BING 중 한 명을 고르는 대전 게임입니다. 변형을 포함해 15종을 선택할 수 있고, 같은 캐릭터의 변형은 이동·점프·기본 공격 수치를 공유합니다. 상대와 스테이지는 주사위처럼 돌다가 랜덤으로 정해지고, 3판 2선승입니다.

빌드가 필요 없는 정적 사이트입니다. `index.html`, `css/`, `js/`, `assets/`, `.nojekyll`을 저장소 루트에 올립니다.

|---|---|---|

| W | 베이스 로켓 / 뽀뽀 돌진 (랜덤) | E |

| W2 | 저음 지진: 앞쪽 바닥에서 보라색 충격파가 솟아 지상 상대를 띄운다 | E2 |

- **KOF ’96 오마주** — Q는 쿄의 아라가미 연계, E는 이오리의 아오이 하나, W2는 테리의 파워 게이저에서 동작을 참고했습니다. Q·E는 첫 타가 닿아야 다음 타를 이어가고, W2의 저음 지진은 바닥에 예고 원이 생긴 뒤 터집니다.
- 태그기는 태그 버튼으로 발동합니다. 게이지 100%가 필요하고 라운드당 1회입니다.
- 필살기·태그기는 영상이 먼저 재생되고, 공격 버튼이나 화면 탭으로 건너뜁니다.
- 스테이지 13개: 애니세상, 체육관, 도넛가게, 밴드연습장, 콘서트 무대, 옥상, 해변, 놀이공원, 눈마을, 우주정거장, 아쿠아리움, 한옥 야시장, 지하실

## 온라인 대전

`대전 → 사설 게임 → 온라인 방 만들기`를 누르면 6자리 방 코드가 뜹니다. 상대는 `방 참가`에 코드를 넣거나 초대 링크(`?room=코드`)로 들어옵니다. 둘 다 캐릭터를 고르고 준비를 누르면 시작합니다.

- 두 기기가 직접 연결(WebRTC)되고, 접속 중개는 무료 공용 PeerJS 서버를 씁니다. 별도 서버나 가입이 필요 없습니다.
- 방을 만든 쪽 기기가 게임을 계산하고 상대는 화면을 받아 봅니다. 참가한 쪽은 회선 상태만큼 입력이 늦게 반영됩니다.
- 온라인에서는 필살기 영상을 건너뛸 수 없습니다.
- `assets/lib/peerjs.min.js`가 접속 라이브러리입니다. 지우면 온라인 대전이 동작하지 않습니다.

파일 키: Q, W, E, R, G(EGG), B(BING), Qb(Q2), Wb(W2), Eb(E2), Rb(R2), Qc(Q3), Wc(W3), Ec(E3), Rd(R3), Rc(R4).
태그 영상은 한 쌍이 하나를 같이 씁니다: `sp_GT`(EGG·BING), `sp_QbT`(Q2·R2), `sp_WbT`(W2·E2), `sp_QcT`(Q3·R3), `sp_WcT`(W3·E3), `sp_RcT`(R4).
영상 파일이 없는 기술은 영상 없이 짧은 정지 연출 후 바로 발동합니다.

## 배경음악

`assets/audio/bgm.mp3`를 반복 재생합니다. 메인 메뉴의 설정에서 배경음악과 효과음 볼륨을 각각 조절할 수 있습니다.

## 아이폰 Safari 확대 문제

공격 버튼을 빠르게 두 번 누르면 화면이 확대되던 문제를 막아 두었습니다. 이 처리는 `index.html`과 `js/input.js`에 있으므로 배포 쪽에서 따로 덧붙일 필요가 없습니다.

## GitHub Pages 배포

1. 저장소 루트에 이 폴더의 모든 파일을 올린다(`.nojekyll` 포함).
2. Settings → Pages → Source `Deploy from a branch`, Branch `main` / `/ (root)`.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/`에서 연다.

## 조작

- 폰: 왼쪽 패드(좌우 이동, 위 점프, 아래 가드), P 펀치, K 킥, 필살, 태그
- PC: 방향키 + Z·X·C·V, 또는 WASD + J·K·L·;

## 빠른 대전과 누적 랭킹

타이틀 화면에서 2~16자 닉네임을 입력한 뒤 대전, 순위, 설정 중 하나를 고릅니다. 빠른 대전은 일반 대기열을 사용하고, 랭킹전은 점수가 비슷한 상대를 먼저 찾습니다. 시즌 1 랭킹 점수는 1,000점에서 시작하며 승리하면 25점, 패배하면 15점을 잃습니다. 순위표에는 랭킹전 기록이 있는 상위 50명이 표시됩니다.

로그인 없이 플레이하며 브라우저에 저장된 무작위 키가 랭킹 기록을 식별합니다. 닉네임은 표시용이라 같은 닉네임을 입력해도 다른 기기의 기록에 접근할 수 없습니다. 브라우저 데이터를 지우면 그 기록을 다시 연결할 수 없습니다.

기존 PeerJS 대전을 사용합니다. 랭킹전은 두 브라우저가 동일한 승자를 보고하면 한 번만 점수를 반영합니다. 경기 시뮬레이션은 방장 브라우저에서 실행되므로 서버 판정 및 조작 방지 기능은 제공하지 않습니다. 연결이 끊겨 양쪽 결과가 도착하지 않은 경기는 점수를 반영하지 않습니다.

### 온라인 API 운영

공개 게임의 매칭과 누적 랭킹은 [운영 API](https://qddup-online-api.gary00.chatgpt.site/leaderboard)에 연결됩니다. 브라우저는 GitHub Pages에서 게임을 실행하고, API는 별도의 D1 데이터베이스에 대기열과 전적을 저장합니다.

`online/`에는 API의 독립 배포용 Worker와 D1 마이그레이션이 있습니다. 다른 Cloudflare Worker로 이전하려면 `wrangler.jsonc`에 D1 데이터베이스 ID를 설정하고 마이그레이션과 Worker를 배포한 다음 `index.html`의 `online-api` 주소를 수정하세요.

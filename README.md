# 큐떱대전

Q·W·E·R 중 한 명을 골라 CPU와 싸우는 1인용 대전 게임입니다. 상대와 스테이지는 주사위처럼 돌다가 랜덤으로 정해지고, 3판 2선승입니다.

빌드가 필요 없는 정적 사이트입니다. `index.html`과 `assets/` 폴더를 그대로 올리면 동작합니다.

## 구성

- 캐릭터 4명: Q(드럼), W(베이스), E(기타), R(보컬)
- 필살기: 필살 버튼을 누르면 캐릭터별 2종 중 하나가 랜덤으로 나옵니다.
- 태그기: 태그 버튼으로 발동합니다. 게이지 100%가 필요하고 라운드당 1회입니다. 조합은 Q+R, W+E, E+R, R+W입니다.
- 필살기·태그기는 영상이 먼저 재생되고, 공격 버튼이나 화면 탭으로 건너뜁니다.
- 스테이지 12개: 애니세상, 체육관, 도넛가게, 밴드연습장, 콘서트 무대, 옥상, 해변, 놀이공원, 눈마을, 우주정거장, 아쿠아리움, 한옥 야시장

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체(화면, 로직, 효과음 합성) |
| `assets/Q.webp` `W.webp` `E.webp` `R.webp` | 캐릭터 동작 스프라이트 |
| `assets/*_face.webp` | 캐릭터 얼굴 |
| `assets/bg_*.jpg` `th_*.jpg` | 스테이지 배경 12종과 미리보기 |
| `assets/sp_Q.mp4` 등 12개 | 필살기 영상(기본, `2` = 두 번째, `T` = 태그) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하게 하는 빈 파일 |

## 배경음악

`assets/bgm.mp3`가 있으면 그 곡을 반복 재생하고, 없으면 스테이지별 합성 음악이 나옵니다. 이 묶음에는 `bgm.mp3`가 없습니다. 구매한 음원은 공개 저장소에 올리지 마세요.

## 아이폰 Safari 확대 문제

공격 버튼을 빠르게 두 번 누르면 화면이 확대되던 문제를 막아 두었습니다. 조작 영역의 터치 기본 동작과 확대 제스처를 차단하고, 터치가 취소되거나 화면이 포커스를 잃으면 눌린 버튼 상태를 초기화합니다. 이 처리는 `index.html` 안에 있으므로 배포 쪽에서 따로 덧붙일 필요가 없습니다.

## GitHub Pages 배포

1. 저장소 루트에 이 폴더의 모든 파일을 올린다(`.nojekyll` 포함).
2. Settings → Pages → Source `Deploy from a branch`, Branch `main` / `/ (root)`.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/`에서 연다.

- PC: 방향키 + Z·X·C·V, 또는 WASD + J·K·L·;
